# Lexventure
Lexventure is an interactive web-based memory game designed to help users learn and reinforce English vocabulary through play.

The game is organized into thematic categories such as travel, work, and daily life, allowing users to practice relevant vocabulary in a structured and engaging way.

It transforms traditional vocabulary learning into a dynamic and visual experience, making the process more intuitive and enjoyable.

The project is built using HTML, CSS, and JavaScript, and is designed with scalability in mind, allowing future expansions such as phrasal verbs, irregular verbs, and additional learning modes.

This project is part of a learning journey focused on building interactive web applications and applying real-world development practices.

Project status: In progress
